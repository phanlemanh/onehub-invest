Vì sao làm

data-api/ là API công khai (đi kho public onehub-data-api). Cả bốn đường của data-api/src/routes/markets.ts đọc bảng của S02 qua area_sources nguồn S02: danh sách trả marketScore và xếp theo điểm S02; chi tiết trả khối marketScore năm điểm con; submarkets nối bảng chỉ số tiểu vùng của S02; insights trả trọn chuỗi tháng của S02. AGENTS.md luật 5: số S02 chỉ để hiệu chuẩn, chỉ hiện ở /ops/quality — không lên API công khai. Bản app của cùng lỗi (/api/v1/markets) đã sửa ở HT23 (_acceptance/api-markets-khong-tra-so-s02, gộp): bỏ marketScore, xếp theo số tin. HT19 và PB3 đã gộp. Hiện API chưa mở cho bên ngoài: project chưa có DATA_API_KEYS, chưa triển khai — số S02 đang nằm trong mã sẽ đi ra API ngay khi mở; đổi hình bây giờ không gãy người gọi nào.
