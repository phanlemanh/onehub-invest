Đã hứa

  3. AC-3 — Given bản tin THẬT còn tươi với khối `lockdown` có đủ ba giá trị lớp (`true`, `false`, `null`) và
  4. AC-4 — Given cùng bản tin với mốc đo của khối lùi 46′, When dựng trang, Then mọi hàng giữ nhãn của khối nhưng 0 badge
  5. AC-5 — (cross-layer) Given bản tin THẬT rút từ `push-ops-facts`, với lớp «Cổng Kev :8009» và «Cổng nhận tin :9210» của
  6. AC-6 — Given DB máy thu đủ bảng (`source_registry` có mặt), When dựng `/ops/collections`, Then lưới Khoá an toàn lấy từ
  7. AC-7 — Given bảng trạng thái của đặc tả UX, chữ thật của lưới, ô và Máy móc, When đối chiếu với ADR-0014,
  8. AC-8 — Given lint UI của kho, When `npm run lint` + `npm run test:lint-rules`, Then sạch — không màu thô, không chữ dưới
  9. AC-9 — Given dev server chạy với lược đồ như máy chủ ở ba trạng thái (không có / tươi / cũ 46′), When mở
