Hệ thống SẼ làm

Sẽ báo đỏ có tên khi một API có trên đĩa mà chưa khai trong sổ, sổ còn dòng của API đã xoá, hoặc phương thức gọi lệch sổ.

Sẽ báo đỏ khi một API khai công khai mà đọc bảng tin rao — kể cả đọc gián tiếp qua thư viện nó dùng.

Sẽ báo đỏ khi cổng quyền trong mã khác chế độ sổ khai (vận hành, vận hành đăng nhập, quản trị, khách được bỏ qua).

Sẽ đóng API danh sách tin rao như đã đóng API căn giá tốt: khách và tài khoản thường nhận 401, khoá vận hành và người vận hành đăng nhập vẫn đọc được; bản kiểm toàn hệ thống đo đúng chế độ mới.

Sẽ từ chối tải ảnh QR đăng nhập Zalo qua đường ảnh, kể cả qua lối tắt đổi tên; ảnh tin thường vẫn xem được, và màn đăng nhập Zalo ở trang vận hành không đổi.

Sẽ cho bài kiểm tra API căn giá tốt tự từ chối chạy khi đang trỏ vào cơ sở dữ liệu không phải máy local (vá hạn chế Ngoài-1 của AU2).

Sẽ ghi vào tài liệu cổng: sổ ở đâu, năm chế độ nghĩa là gì, và luật API đọc bảng tin rao không được công khai.
