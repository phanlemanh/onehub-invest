## A1 — runtime/ loop + trace (1 buổi)

### Files tạo
```
agent/package.json          # deps: ai@^7 (Vercel AI SDK), zod; scripts: test
agent/tsconfig.json
agent/src/runtime/models.ts # router model
agent/src/runtime/loop.ts   # harness loop
agent/src/runtime/context.ts# budget + offload
agent/traces/.gitkeep       # traces (gitignore *.jsonl)
agent/tests/loop.test.ts
```

### Thiết kế then chốt
- `models.ts`: `getModel(name)` qua AI SDK `createOpenAI({baseURL})`:
  - `qwen27b` → `http://127.0.0.1:8000/v1` (MTPLX; model
    `mtplx/qwen3.8-27b-local`, reasoning low, maxTokens ≥2000 — bẫy cũ)
  - `kev4b` / `decisions` → HTTP fetch trực tiếp (không qua AI SDK —
    contract `/v1/systemone` questions[] riêng)
- `loop.ts` — `runAgent({agent, input, budget?})`:
  - AI SDK `generateText` với `tools` (zod schemas), `stopWhen: stepCountIs(budget ?? 8)`
  - hooks: `onStep(step)`, `onToolCall(name,args)`, `onToolResult(name,result)`
    — mọi hook ghi trace; lỗi hook KHÔNG dừng loop (bài học fail-soft)
  - trace: `agent/traces/<ISO>-<agent>.jsonl` — mỗi dòng
    `{t, step, type: model|tool|final, ...}`; trả về
    `{output, steps, tracePath}`
  - `context.ts`: `offload(result)` giữ 500 ký tự đầu/cuối + lưu đầy đủ
    vào trace (chuẩn T2 tool-offloading)
- `agents-as-config`: agent = `{name, model, systemPrompt, tools, budget}``
  plain object — KHÔNG class, KHÔNG framework.

### TDD

### Verify

## A2 — judge-entity trên 124 cặp (1 buổi + 1 slot eval)

### Files
```
agent/src/tools/native.ts       # queryPair(offerA, offerB) → đọc DB
agent/src/agents/judge-entity.ts # config agent
agent/scripts/judge-eval.mjs     # eval 30 cặp
agent/scripts/judge-run.mjs      # chạy toàn bộ 124
```

### Luồng
1. `native.queryPair`: SELECT 2 offers (giá/DT/perm2/phường/kind/
   property_type) + text gốc từ stg_zalo_posts (P1) / subject (P2).
2. Agent config judge-entity: model qwen27b, systemPrompt yêu cầu
   **choice** `{same_house: yes|no|unsure, confidence, evidence:[...]}`
   — questions[] typed (hợp đồng chốt); KHÔNG cho tool ghi DB (chỉ đọc).
3. `judge-run.mjs` (đêm): query candidates `needs_llm` → lần lượt qua
   runtime → `UPDATE property_candidates SET status =
   CASE same_house WHEN 'yes' THEN 'merged' WHEN 'no' THEN 'rejected'
   ELSE 'pending' END, decided_by='llm-judge', detail=<evidence+trace path>`
   — KHÔNG đụng properties/property_offers (merge vật lý là PR sau khi
   user soi mẫu).
4. **Eval TRƯỚC**: `judge-eval.mjs` — tôi/user hand-label 30 cặp đầu
   (sheet), chạy judge trên 30, in accuracy + ma trận nhầm. Gate:
   ≥0.80 mới mở `judge-run`.

### TDD
- Unit: render prompt từ 1 fixture cặp (77,8tr↔77,8tr đã có sẵn) — assert
  chứa 2 perm2, DT, phường.
- Integration (không CI): judge 5 cặp thật in kết quả để đọc.

### Verify
```bash
npx tsx scripts/judge-eval.mjs   # accuracy ≥0.80
npx tsx scripts/judge-run.mjs    # 124 cặp, ~20-30 phút (9s/cặp Qwen)
psql: SELECT status, count(*) FROM property_candidates GROUP BY 1;
```
✅ DoD: eval đạt gate + chạy xong 124 + status phân bố hợp lý + trace
mọi phán quyết.

## M1 — migration memory (nửa buổi)

`db/migrations/028_user_memory.sql`:
```sql
CREATE TABLE user_events (
  id bigserial PRIMARY KEY,
  user_id text NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  kind text NOT NULL,            -- view_market|saved_market|compare|dau_tu_input|advisor_msg
  payload jsonb NOT NULL DEFAULT '{}',
  source text NOT NULL DEFAULT 'app' CHECK (source IN ('app','advisor')),
  at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX user_events_user_idx ON user_events(user_id, at DESC);

CREATE TABLE user_profile (
  user_id text NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  key text NOT NULL,             -- budget_pct|target_cities|property_prefs|goal...
  value jsonb NOT NULL,
  source text NOT NULL CHECK (source IN ('declared','behavior','feedback')),
  evidence_event_ids bigint[] NOT NULL DEFAULT '{}',
  valid_from timestamptz NOT NULL DEFAULT now(),
  valid_to timestamptz,          -- bi-temporal: fact mới → đóng cũ (KHÔNG xoá)
  PRIMARY KEY (user_id, key, valid_from)
);
CREATE INDEX user_profile_active_idx ON user_profile(user_id) WHERE valid_to IS NULL;

-- Seed episodic từ saved_markets
INSERT INTO user_events (user_id, kind, payload)
SELECT user_id, 'saved_market', jsonb_build_object('area_id', area_id) FROM saved_markets;
```
Guard: KHÔNG thêm vào sync-cloud FILL (PII tầng A — cùng luật sellers).

✅ DoD: migration chạy; `SELECT count(*) FROM user_events` ≥ số saved.
