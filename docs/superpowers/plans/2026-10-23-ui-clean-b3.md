# B3 — Thống nhất biểu đồ: kế hoạch thi công

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (chạy tuần tự trong phiên chính — các task đụng chung chart.tsx). Steps dùng `- [ ]`.

**Goal:** Ba biểu đồ (performance/chart-6, revenue-mix/chart-13, pnl/chart-36) lấy màu từ một bảng màu chung theo nghĩa, dùng chung phần mã chép trùng ở `components/charts/`, mọi file ≤ 200 dòng — DOM, chữ, thao tác, CSV, toast giữ nguyên.
