# Đợt B1 — dọn cổng Ops (shell Ops + block Solutions) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cổng Ops chạy trong shell riêng (chuyển thể `app-shell-36`) và các trang dựng từ block Solutions đã duyệt, không còn UI tự vẽ tay, không đổi dữ liệu/query/API.

**Architecture:** Block Pro cài nguyên bản vào `components/blocks/<tên>/` (vendor, không sửa, lint onehub-ui không quét). Bản chuyển thể nằm ở `components/ops/<trang>/` và `components/shell/ops-shell/`: chép phần dùng được, thay dữ liệu mẫu bằng props từ query sẵn có, bỏ vùng không có dữ liệu thật. Trang server (`app/ops/**/page.tsx`) chỉ đọc query cũ rồi truyền props. Một harness `scripts/ui-standards/b1-ops.mjs` chứa mọi phép kiểm máy của evals.

**Tech Stack:** Next.js 16 App Router, Base UI (style `base-nova`), ReUI data-grid/frame/filters, shadcn sidebar, sonner, TypeScript AST (`typescript` của `app/node_modules`) cho harness, `node --test` cho test plugin lint.

**Spec:** `docs/superpowers/specs/2026-10-23-ui-clean-b1-ops-design.md` · hợp đồng `_acceptance/ui-clean-b1-ops/contract.md` (12 AC) · `evals.yaml` (16 eval).
